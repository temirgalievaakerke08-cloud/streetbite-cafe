# FAMOUZ Burger 🍔

## Project Description

FAMOUZ Burger is a responsive restaurant website created as part of a Web Technologies assignment. The website presents a modern burger restaurant where users can explore the menu, learn about the restaurant, register, and contact the team.

The project focuses on HTML, CSS, JavaScript, jQuery, responsive design, and user interaction.

## Technologies Used

- **HTML5** — website structure.
- **CSS3** — styling and responsive layouts.
- **JavaScript** — interactive functionality.
- **jQuery** — DOM manipulation, event handling, filtering, animations, and form validation.
- **Bootstrap 5** — additional styling and form components.
- **Git and GitHub** — version control and project collaboration.
- **GitHub Pages** — website deployment.

## Website Pages

The website contains five main pages:

1. **Home (`index.html`)** — homepage with a welcome message and dark/light mode button.
2. **Menu (`services.html`)** — burger menu with live search, category filters, and a personal favorites list.
3. **About (`about.html`)** — information about the restaurant.
4. **Contact (`contact.html`)** — contact information, validated contact form, and animated FAQ section.
5. **Register (`register.html`)** — user registration page.

## Main Features

- Interactive welcome message using jQuery.
- Dark and light theme switching.
- Live menu search.
- Menu filtering by categories.
- Dynamic favorites list with add and remove functionality.
- Animated FAQ accordion.
- Contact form validation.
- Responsive layout for mobile, tablet, and desktop screens.
- Navigation between all website pages.

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html`.
4. Use the Live Server extension to launch the website in your browser.
5. Navigate through the pages using the navigation menu.

jQuery is included through the official jQuery CDN, so an internet connection is required for its features.
